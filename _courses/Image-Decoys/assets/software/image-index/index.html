Image Index

A mock image search engine. It reads the real metadata inside every file, gives each image a score and sorts them. You decide what counts: move the sliders, search, click an image to see what the index knows about it, or add your own photographs.

Add your own images

JPG / JPEG files only. Other formats (PNG, HEIC, WebP) store metadata differently and are not read here.

Files are read in your browser only. Nothing is uploaded to a server, and they disappear when you reload.

Change the metadata of a file

Edit the file with a metadata tool, then drop it here again: a file with the same name replaces the earlier one. With ExifTool: 

exiftool -Make="Apple" -Model="iPhone 15 Pro" photo.jpg
exiftool -DateTimeOriginal="2026:11:19 08:00:00" photo.jpg
exiftool -all= photo.jpg

The last one strips everything. See the tutorial for more.
